Rundock runs locally. There is nothing to provision and no account to create. You need a **Claude Pro or Max subscription** (Claude Code runs your team by default). You do not have to set Claude Code up by hand first: Rundock's first-run wizard detects it, helps you install it if it is missing, and signs you in with one click.

A **ChatGPT plan** can run agents too: any specialist can run on the official Codex CLI instead of Claude Code. That setup is currently manual (two terminal commands) and the orchestrator still runs on Claude Code; see [Runtimes](/concepts/runtimes).

Download Rundock for your platform:

| Platform | Download |
|---|---|
| macOS (Apple Silicon or Intel) | Universal `.dmg` |
| Windows 10 or 11 (64-bit) | `.exe` installer |
| Linux | [Build from source](#linux-and-build-from-source) |

Get both downloads from [rundock.ai/download](https://rundock.ai/download) or the [GitHub releases page](https://github.com/liamdarmody/rundock/releases).

## macOS

One universal build runs natively on both Apple Silicon and Intel Macs. There is no separate Intel download and no architecture to pick.

### 1. Download Rundock

Get the universal `.dmg` from [rundock.ai/download](https://rundock.ai/download).

### 2. Install it

Open the `.dmg` and drag the Rundock icon to your Applications folder. Eject the `.dmg` once the copy completes.

### 3. Open Rundock

Open Rundock from Applications, Spotlight, or Launchpad. The app is signed and notarised by a verified Apple developer, so it launches without Gatekeeper warnings.

On first launch, the setup wizard checks for Claude Code, helps you install it if needed, and signs you in. Continue to [first-run setup](/first-run).

## Windows

A native installer for Windows 10 and 11 (64-bit).

### 1. Download the installer

Get the `.exe` installer from [rundock.ai/download](https://rundock.ai/download).

### 2. Run it

The build is unsigned for now, so Windows SmartScreen shows a one-time prompt the first time you run it. Click **More info**, then **Run anyway**. Finish the installer; it adds a Desktop shortcut and a Start Menu entry.

If the message comes from **Smart App Control** instead and there is no **Run anyway**, see [Smart App Control](#smart-app-control) below.

### 3. Open Rundock and sign in

Open Rundock from the Desktop shortcut or Start Menu. The setup wizard:

- Detects Claude Code, and shows the one-line install command (PowerShell or WinGet) if it is missing.
- Adds Claude Code to your PATH so `claude` works in a terminal.
- Gives you a one-click **Sign in to Claude** button. It opens a terminal window running Claude Code's sign-in, which hands off to your browser. Follow its prompts; there are no commands to type.

Once the wizard shows both steps complete, continue to [first-run setup](/first-run).

### Smart App Control

Smart App Control is a Windows 11 security feature that only lets an app run when Windows can verify it. Until the Windows build is signed, it blocks the Rundock installer. The message says Windows couldn't verify the app's publisher, and its only choices are to close it or to get apps from the Microsoft Store. There is no **Run anyway**, and Smart App Control has no way to allow a single app.

Keep Smart App Control on. Turning it off to install Rundock would also stop it protecting you from every other unverified app. If you choose to switch it off anyway, read Microsoft's [Smart App Control FAQ](https://support.microsoft.com/windows/smart-app-control-faq-285ea03d-fa88-4d56-882e-6698afdb7003) first.

Until the signed build is out, you can run your team in Claude Code, which Anthropic signs for Windows:

1. Install Claude Code: open PowerShell and run `winget install Anthropic.ClaudeCode`. Claude Code's [setup guide](https://code.claude.com/docs/en/setup) lists the other ways to install it.
2. In PowerShell, go to your workspace folder (the one that contains the `.claude` folder) and run `claude`. Sign in when it asks. To start as a particular agent, such as your orchestrator, run `claude --agent <slug>` instead.

Your agents, skills and `CLAUDE.md` are the same files Rundock reads, so there is nothing to convert (see [Agents are portable](/concepts/agents#agents-are-portable)). What you don't get in the terminal is Rundock itself: the visual workspace, the org chart and routines. When the signed build is out, install it and open the same folder.

<Note>
The Windows build is unsigned for now, which is why SmartScreen prompts on first launch. The click-through above is safe and only appears once. Signing is on the roadmap.
</Note>

## Linux and build from source

For Linux, or anyone who wants to run Rundock from source. This is also the contributor path.

### Requirements

- Node.js 22 or later. Check with `node --version`.
- Claude Code installed and authenticated. Confirm with `claude --version`.

### Clone, install, and run

```bash
git clone https://github.com/liamdarmody/rundock.git
cd rundock
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Rundock runs in the browser and behaves the same as the desktop app.

If you want to modify Rundock or contribute changes, this is the route to take. [CONTRIBUTING.md](https://github.com/liamdarmody/rundock/blob/main/CONTRIBUTING.md) in the repository covers it in more depth.
